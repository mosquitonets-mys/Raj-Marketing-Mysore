💻 Optimization Commands

Using ImageMagick

# Optimize all JPG images for img in images/**/*.jpg; do convert "$img" -strip -interlace Plane -quality 75 "$img" done # Resize all images to max width for img in images/**/*.jpg; do convert "$img" -resize 1200x1200\> -quality 75 "$img" done # Create WebP versions for img in images/**/*.jpg; do cwebp -q 75 "$img" -o "${img%.jpg}.webp" done

Using Python (Pillow)

from PIL import Image import os def optimize_image(path, quality=75): img = Image.open(path) if img.mode in ('RGBA', 'P'): img = img.convert('RGB') img.save(path, 'JPEG', quality=quality, optimize=True, progressive=True) for root, dirs, files in os.walk('images'): for file in files: if file.endswith(('.jpg', '.jpeg')): path = os.path.join(root, file) optimize_image(path)

⚡ Lazy Loading Implementation

Add to your HTML for faster page load

<!-- Lazy loading attribute --> <img src="image.jpg" alt="Description" loading="lazy"> <!-- With fallback --> <img src="image.jpg" alt="Description" loading="lazy" onerror="this.src='fallback.jpg'"> <!-- Responsive with srcset --> <img src="image-small.jpg" srcset="image-small.jpg 400w, image-medium.jpg 800w, image-large.jpg 1200w" sizes="(max-width: 600px) 400px, (max-width: 1200px) 800px, 1200px" alt="Description" loading="lazy">

🚀 Performance Optimization Tips

  1. Use WebP format - 30% smaller than JPG
  2. Progressive JPG - Better perceived load time
  3. Lazy loading - Load images only when needed
  4. Responsive images - Use srcset for different screen sizes
  5. CDN - Serve images from a CDN
  6. Cache headers - Set proper cache control
  7. Image sprites - Combine small images
  8. SVG for icons - Scalable and small size

Optimize Images

Convert to WebP
